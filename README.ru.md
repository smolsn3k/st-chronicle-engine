# Chronicle Engine

[English](README.md) | **Русский**

Сюжетный движок для [SillyTavern](https://github.com/SillyTavern/SillyTavern). Стройте собственные миры в виде **хроник**, состоящих из арок, эпизодов и сюжетных битов, а затем позвольте модели следовать вашей структуре, пока вы сами управляете темпом.

Работает на компьютере и на телефоне. Прогресс сохраняется отдельно для каждого чата.

> **Статус: v0.1.0.** Первый релиз, написан под SillyTavern 1.13+. Если что-то сломалось в вашей версии, пожалуйста, создайте issue.

## Установка

1. В SillyTavern откройте **Extensions** (Расширения) → **Install extension** (Установить расширение).
2. Вставьте `https://github.com/smolsn3k/st-chronicle-engine` и установите.
3. Перезагрузите SillyTavern. Появится плавающая кнопка с книгой. Нажмите на неё, чтобы открыть Chronicle Engine.

## Язык интерфейса

Интерфейс доступен на английском и русском. По умолчанию выбран режим **Авто**: язык берётся из настроек SillyTavern, а если он не распознан, из языка браузера. Сменить язык можно в любой момент двумя способами:

- на вкладке **Функции** → **Общие** → **Язык**;
- в панели расширения Chronicle Engine в настройках расширений SillyTavern.

Смена языка применяется сразу, без перезагрузки страницы.

Что именно переключается:

- **Интерфейс**: вкладки, кнопки, подсказки, уведомления и диалоги.
- **Вспомогательные задачи**: при выбранном русском языке модель просят писать пересказы, эпилоги, подсказки «Что дальше?», результаты проверок и сгенерированные хроники по-русски.
- **Не переключается** скрытая подсказка, которая добавляется в промпт во время чата. Она остаётся на английском, потому что её никто не видит, а модели лучше всего следуют таким инструкциям именно на английском. На язык вашей ролевой игры она не влияет.

Названия по умолчанию («Хроника 1», «Арка 1», «Эпизод 1», «Первый бит») создаются на выбранном языке. Уже созданные хроники не меняются.

## Быстрый старт

1. Откройте панель и перейдите на вкладку **Редактор** (Edit). Создайте хронику, добавьте арку, эпизод и несколько битов.
2. Перейдите на вкладку **Панель** (Dashboard) и выберите хронику для своего чата.
3. Общайтесь как обычно. В промпт добавляются активный бит, название следующего бита, краткое описание арки и инструкция по темпу.
4. Пользуйтесь кнопками **Завершить бит**, **Пропустить**, **Откатить** и **Ветка**, когда история движется вперёд.

Хотите сначала посмотреть готовый пример? Импортируйте `examples/example-chronicle.json` через **Миры** (Worlds) → **Импорт из файла**.

## Основные понятия

| Уровень | Что это |
| --- | --- |
| Хроника | Вся ваша кампания с необязательным связанным лорбуком |
| Арка | Крупный раздел с кратким описанием и необязательным собственным темпом |
| Эпизод | Группа битов внутри арки |
| Бит | Один сюжетный пункт: описание, цели, обязательные события и приоритет: *обязательно* или *желательно* |

Состояния бита: **закрыт**, **активен**, **завершён**, **пропущен**, **разветвлён**.

**Ветка** — это бит, который указывает на другой бит того же эпизода и имеет описание условия. С активного бита можно уйти в ветку, а после её завершения история возвращается на основную линию.

## Возможности

- **Панель** с индикаторами прогресса, сегментированной лентой истории для каждой арки и эпизода и быстрыми действиями
- **Темп**: Медленный, Обычный, Ускоренный, с возможностью задать свой темп для каждой арки
- **Динамический толчок**, когда чат буксует (без дополнительного запроса к модели)
- **Проверка бита**: спрашивает модель, произошли ли события бита, а затем просит вас подтвердить
- **Краткий пересказ арки**, **генератор эпилога**, **«Что дальше?»**, **подсказки для лорбука**, **проверка согласованности** (каждую функцию можно включить или выключить)
- **Миры**: привязка лорбука, редактирование его записей, генерация хроники из лорбука или по известной истории, импорт и экспорт в JSON (по желанию вместе с лорбуком)
- **Профили подключения**: выбор профиля для вспомогательных задач (пересказы, проверки, генерация), обновление списка и переключение профиля чата
- **Включение и выключение** глобально и отдельно для каждого чата, а также перемещаемая плавающая кнопка, которую можно скрыть

## Примечания

- **Где хранятся данные:** хроники и настройки хранятся в настройках расширений SillyTavern. Прогресс по каждому чату хранится в метаданных этого чата.
- **Вспомогательные задачи и профили:** вспомогательные задачи используют сервис запросов Connection Manager, если он доступен. В противном случае они работают через ваше текущее подключение.
- **Сгенерированные хроники — это черновики.** Модели могут ошибаться в деталях сюжета. Проверяйте их перед использованием.
- **Проверка согласованности** пока запускается вручную. Она сверяет несколько последних сообщений с завершёнными битами и связанным лорбуком.

## Формат JSON хроники

```json
{
  "format": "chronicle-engine",
  "version": 1,
  "chronicle": {
    "title": "",
    "description": "",
    "lorebook": "",
    "characters": [],
    "arcs": [
      {
        "title": "",
        "summary": "",
        "pacing": "slow | normal | fast | empty",
        "episodes": [
          {
            "title": "",
            "beats": [
              {
                "id": "optional, used to link branches",
                "title": "",
                "description": "",
                "goals": [],
                "requiredEvents": [],
                "priority": "must | should",
                "branchOf": "id or title of a beat in the same episode",
                "branchTrigger": ""
              }
            ]
          }
        ]
      }
    ]
  },
  "lorebook": { "name": "", "data": {} }
}
```

Ключи и служебные значения (`must`, `should`, `slow`, `normal`, `fast`) всегда пишутся по-английски, независимо от языка интерфейса. Тексты (названия, описания, цели и так далее) можно писать на любом языке.

Блок `lorebook` верхнего уровня необязателен и добавляется при экспорте с включённой опцией «Включить лорбук».

## Добавление нового языка

Переводы лежат в папке `locales/`. Ключом служит английская строка из кода, поэтому всё, что не переведено, автоматически показывается по-английски.

1. Скопируйте `locales/ru.js` в `locales/<код>.js` (например, `de.js`) и переведите значения. Плейсхолдеры вида `{name}` оставляйте без изменений.
2. Подключите файл в `i18n.js`: добавьте импорт, запись в `DICTS` и пункт в `LANGUAGES`.

Pull request с новым переводом приветствуется.
